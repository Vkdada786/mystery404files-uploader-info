Privacy policy

This policy describes the personal Mystery404files Uploader operated by GitHub user Vkdada786. It covers the uploader and distinguishes it from this public information website.

Data accessed and purpose

With the owner's Google authorization, the uploader accesses the authorized YouTube channel's identity, queued Drive video content, filenames, file IDs, MIME types and sizes, folder membership, and app-specific upload-state properties. It sends the selected video, filename-derived title, configured description and audience/privacy settings to YouTube, then reads processing and publication status.

The Drive authorization can permit broader read/write access to the owner's Drive. The implementation limits its operations to the configured queue and destination folders and their queue metadata. Access is used to list and download queued videos, update upload state, and move successfully published originals. YouTube access is used to verify the channel, upload videos and check their status.

Processing and sharing

GitHub Actions temporarily processes the selected video on a hosted runner. Google Drive stores the original; YouTube receives and stores the uploaded copy. Public YouTube uploads are visible to others under the owner's publication settings. The uploader does not sell Google user data, use it for advertising, or send it to AI services for model training.

People with authorized access to the owner's private automation repository may be able to see workflow logs, including video filenames, upload IDs, statuses and errors. GitHub and Google handle data under their own service policies. Facebook publishing is disabled in the current configuration.

Storage, security and retention

OAuth credentials are stored in GitHub Actions encrypted secrets for the private uploader repository. The owner may also hold local client and token files on their laptop. Credentials, token files and video content are not included in this public website repository. Temporary downloaded video copies are removed when the uploader's temporary directory is cleaned up or the hosted job workspace is disposed of.

Original videos remain in the owner's Drive and are moved to Published after confirmed successful publication. The uploader does not delete originals. Upload IDs and state metadata remain on Drive files and folders until the owner removes them or the files. YouTube copies remain until the owner deletes them in YouTube. Logs and repository history follow the owner's GitHub retention settings; changing a secret does not erase earlier logs or local files.

Control, revocation and deletion

The owner can stop scheduled publishing by setting PUBLISH_ENABLED=false in the uploader repository, revoke the app's access from the Google Account's third-party connections settings, and remove the Drive and YouTube OAuth secrets from GitHub Actions. Local token files can be removed separately. Revoking access stops future authorized access; it does not delete existing Drive files or YouTube uploads. The owner controls those copies through the corresponding Google services.

Google API data use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

This public website

The site has no account system, forms, advertising, custom analytics or application cookies. GitHub Pages may process connection and server-log information under GitHub's privacy statement. Merely visiting this site does not grant the uploader access to Google data.

Contact and changes

Contact the operator through the information repository's issue tracker. Issues are public: never post passwords, tokens, private videos or personal account details. As this is an owner-operated app, account-data requests should be carried out by the owner through Google and GitHub account controls. Policy updates will be published here with an updated date.
